Portfolio Website

Quick start:

1. Open `index.html` in your browser (double-click or use a local server).

Notes:

- Replace placeholder text (Your Name, project descriptions, email) with your own content.
- No build step required — static HTML/CSS/JS only.

Optional:

- Serve locally for testing with a simple HTTP server (Python 3):

```bash
python -m http.server 8000
```

Then open http://localhost:8000
